# Russian localization policy

Russian pages should read as Russian professional copy, not as mixed Russian-English jargon.

Translate ordinary business/legal terminology into Russian. Retain only genuine international abbreviations, brand names, product names and professional titles where translation would reduce precision (for example LEXONYX, AML/KYC, FATF, MiCA, OSS/IOSS, FAR, IP, Rechtsanwalt, Steuerberater). Where PE is relevant, visible copy should prefer «постоянное представительство» and use PE only where useful as an international abbreviation.

Preferred terminology examples:
- ownership → структура владения
- governance → корпоративное управление
- substance → фактическое экономическое присутствие
- banking readiness → банковская готовность
- VAT → НДС
- PE-risk → риск постоянного представительства
- transfer pricing → трансфертное ценообразование
- Target State → целевая модель
- Current State → текущая модель
- Entity Necessity → необходимость отдельной компании
- Business Purpose → деловая цель
- workstream → направление работы
- cross-border → трансграничный
- Source of Funds / Source of Wealth → происхождение средств / происхождение капитала
